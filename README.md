# 倒数日

一个简洁优雅的倒数日 Web 应用，帮助你记录重要日期的倒数与正数。

**🌐 在线体验：[countdowndaily.netlify.app](https://countdowndaily.netlify.app/)**

## 功能

- 创建倒数日（距某天还有多少天）与纪念日（已经过去多少天）
- 36 款渐变色卡 + 自定义背景图片
- 图标/表情符号选择器（含颜文字）
- 实时倒计时（时 / 分 / 秒）
- 里程碑提醒（100 天、1000 天等）
- 分类管理、置顶、备注
- 一键生成并下载分享卡片（PNG）
- 深色 / 浅色主题
- 数据保存在本地（无需登录）

## 技术栈

- React + TypeScript + Vite
- Zustand（状态管理 + localStorage 持久化）
- React Router DOM
- 部署于 Netlify
